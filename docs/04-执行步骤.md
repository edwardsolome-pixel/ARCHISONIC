# 04 · 执行步骤 — ARCHISONIC: UNFINISHED TOUR

> 状态：v1.0（2026-11-10）。开发流程的唯一标准：怎么推进、怎么验收、怎么记录。

## 1. 工作原则

1. 一次只推进一个里程碑，验收通过才进下一个；不过度开发
2. 每步产出可运行、可验收的版本；验收 = 在浏览器按本节标准逐项走查
3. 每里程碑结束：更新 DEVLOG.md → 备份项目文件夹 `e:\ARCHISONIC-demo-2-m{n}-backup`
   （git 未安装；日后安装 git 后可切换为 git 提交，格式 `M{n}: 内容简述`）
4. 向用户汇报实际验收结果（含失败项），由用户确认后才进入下一里程碑

### M4 音频引擎与点击试听

验收：

- [ ] 首次点击出声（顶栏 STANDBY → READY）；点击矩形 = 35ms 错开芯片琶音
- [ ] 移动 / 缩放 / 创建落定后自动试听一次；拖拽过程中不连续发声
- [ ] 音高左右 / 八度上下 / 音量面积 / 和弦比例 听感与面板读数一致
- [ ] VOLUME 滑杆、SCALE 下拉（4 种音阶）生效可听
- [ ] 快速连点 10 个矩形：每响清晰、无爆音、无残留长音

### M5 TOUR 音序器

验收：

- [ ] TOUR 按编号顺序逐个演奏；播放头扫掠与声音对齐；播完自动复位
- [ ] STOP / Esc / Space 立即停止（含正在发声和弦）；按钮态正确
- [ ] 状态文本正确（TOUR ▶ SPACE 03/12）；巡游中编辑锁定，结束后恢复
- [ ] 巡游中拖动 / 删除矩形不崩溃（音频用快照）
- [ ] 0 矩形按 TOUR 不启动；快速 TOUR / STOP 交替 5 次无多重定时器 / 振荡器
- [ ] BPM 滑杆巡游中调整：已排程保持旧速、后续按新速；面板读数实时

### M6 持久化与打磨

验收：

- [ ] 首次运行出现 5 个种子矩形（覆盖 4 和弦档），编号 1–5
- [ ] 编辑 + 调参后刷新：图形与设置完全恢复
- [ ] CLEAR 清空 → 空状态提示；Ctrl+Z 可整体恢复；清空后刷新不重新播种
- [ ] localStorage 损坏（改垃圾串）→ 刷新不崩溃、回退种子
- [ ] 扫描线 / 像素角 / 闪烁块 / 按钮态等视觉细节到位
- [ ] 全流程 E2E：种子 → 试听 → 编辑 → 撤销 → TOUR → 刷新恢复 → 清空

## 3. 会话工作流程（每次开发会话）

1. 读 CLAUDE.md → 按当前里程碑读 docs/01、02、03 对应部分
2. 只做当前里程碑范围内的事
3. 完成或告一段落：按本章验收标准自检 → 向用户汇报实际结果
4. 会话结束前：更新 DEVLOG.md 当日分节（完成 / 待办 / 下一步）
5. 里程碑验收通过：备份 `e:\ARCHISONIC-demo-2-m{n}-backup`

## 4. 全程约束自查（每个里程碑都查）

- [ ] 无网络请求（DevTools → Network 应为空）
- [ ] file:// 双击直接可用（不依赖本地服务器）
- [ ] 无外部依赖（无 CDN / webfont / npm / ES Module）
- [ ] 界面文案英文；代码注释中文
