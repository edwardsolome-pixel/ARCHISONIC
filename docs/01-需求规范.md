# 01 · 需求规范 — ARCHISONIC: UNFINISHED TOUR

> 状态：v2.0（2026-11-10）。v1 产品范围经用户重新定义（平面图矩形 + PAD 音色 + C 大调进行），
> 本文档取代 v1.0 的功能章节，是功能需求的唯一权威来源。

## 1. 产品概述

ARCHISONIC: UNFINISHED TOUR 是一款基于网页运行的交互式建筑绘图与生成音乐软件，
面向桌面浏览器。用户在画布上绘制建筑平面图风格的矩形（地板 + 厚墙体），
按下 PLAY 后按绘制顺序播放 C 大调 PAD 和弦进行；矩形之间相连则和弦无缝衔接，
不相连则中间断开；混响强度由矩形面积决定。

- 运行方式：双击 `index.html` 在浏览器打开（file:// 协议），无安装、无构建、无网络依赖
- 平台：桌面浏览器（Chrome / Edge / Firefox 现代版本），不考虑移动端
- 界面语言：英文（产品气质：复古数字文化、地下电子音乐）

## 2. v1 功能需求

### 2.1 绘图画布（中央大画布窗口 FLOOR PLAN）

智能模式（无需切换工具）：

- 空白处拖拽 = 新建矩形（≥3px 才算拖拽；<16×16px 的拖动视为误触丢弃）
- 点击矩形 = 选中；点击空白 = 取消选中
- 拖拽矩形内部 = 移动；拖拽边/角手柄 = 缩放（自由缩放）
- 矩形最小 16×16px，不超出画布边界；移动/缩放中 Esc 取消并还原
- Delete / Backspace 删除选中矩形；Ctrl+Z 撤销（上限 100 步）
- 网格背景（24px + 96px 强调线，仅显示、不吸附）
- 矩形样式 = 建筑平面图：地板填充 + 周围一圈有厚度的墙体（见 docs/03 §4.5）
- 矩形左上角显示创建顺序编号（= 播放顺序）

### 2.2 和弦系统（C 大调，按矩形数量分配）

| 矩形数 n | 和弦序列（按创建顺序） |
| --- | --- |
| 1 | C |
| 2 | C, F |
| 3 | Dm, G, C |
| 4 | Dm, G, C, Am |
| ≥5 | Dm, G, C, Am 循环（第 5 个 = Dm，第 6 个 = G …） |

- 删除矩形后 n 变化 → 全部矩形的和弦重新计算（基于数量）
- 和弦的具体名称不向用户展示（界面任何位置不显示和弦名）

### 2.3 连接性与乐句

- 相邻两矩形（按创建顺序）共边或重叠 = 连接 → 两和弦无缝衔接（legato，交叉淡入淡出）
- 不相连 → 上一个和弦收尾后停顿约 0.5s，再起下一个（可听见断开）
- 仅角相触不算连接

### 2.4 播放

- PLAY 键 = 按创建顺序播放全部矩形的和弦；播放中按钮变 STOP，按下立即停止（含正在响的和弦）
- 播放中高亮当前发声的矩形（酸绿描边）；播放结束自动复位
- 0 个矩形时按 PLAY 不启动
- 播放中编辑画布不影响本次播放（按播放瞬间快照演奏）

### 2.5 音色

- PAD 软音色：attack 慢（约 0.6s）、冲击力弱、自带混响
- 混响强度由矩形面积决定：面积越大混响越重（映射范围见 docs/02）
- 音量滑杆（默认 70%）

### 2.6 信息面板（2026-11-10 按用户验收反馈修订）

- 顶部信息栏：等宽状态文本（READY / SPACE 02 SELECTED / PLAYING / AUDIO: STANDBY）+ 闪烁状态块
- 左侧栏（竖向三窗口）：
  - 上：「ARCHISONIC」项目名（Arial 等非衬线字体，略下沉居中于暖灰方框）
  - 中、下：空置（后续版本填充）
- 底部面板（横向三窗口）：
  - TRANSPORT（绿色窗口）：VOLUME 滑杆、KEY 与 AUDIO 状态读数
  - PLAYER（绿色窗口）：三角形 PLAY 按钮（播放中变方块 STOP）；窗口内不显示任何和弦名称
  - MANUAL：操作提示（绘制/选择/缩放/删除/撤销/播放）
- 底部状态条：SPACES 计数 · KEY: C MAJOR · 状态
- 画布背景底色：#B5B5B3（中灰）

## 3. 已确认决策（2026-11-10）

v1 产品方案（用户拍板）：

1. PLAY = 顺序播放全部矩形（按创建顺序），相连 legato、不相连有停顿
2. 连接判定 = 共边或重叠（仅角相触不算）
3. 第 5 个矩形起循环 Dm-G-C-Am
4. UI 布局 = 顶部栏 + 中央大画布窗口 + 底部横排小窗口

协作机制：

5. 开发日志：会话驱动（每次开发会话结束由 Claude 自动更新 DEVLOG.md）
6. 版本管理：git（安装于 E:\Git，每里程碑验收后提交，格式 `M{n}: 内容简述`）

## 4. 约束与假设

- 纯前端单文件 index.html，无框架、无构建、无外部依赖、无网络请求、无 ES Module（file:// CORS 限制）
- 声音全部由 Web Audio API 合成（含程序化生成的混响脉冲响应），不加载音频文件
- 字体仅用系统字体（Georgia / Courier New），不使用 webfont
- 配色与字体规范见 docs/03-设计规范.md；技术实现细节见 docs/02-技术方案.md
