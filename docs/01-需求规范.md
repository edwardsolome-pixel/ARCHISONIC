# 01 · 需求规范 — ARCHISONIC: UNFINISHED TOUR

> 状态：v3.0（2026-11-11 全量核对：与 index.html 实际实现逐项比对并修订）。
> 本文档是功能需求的唯一权威来源。

## 1. 产品概述

ARCHISONIC: UNFINISHED TOUR 是一款基于网页运行的交互式建筑绘图与生成音乐软件，
面向桌面浏览器。用户在画布上绘制建筑平面图风格的矩形（地板 + 厚墙体），
在墙上放置门、窗构件；按下 PLAY 后按绘制顺序循环播放和弦进行，
门/窗汇总生成鼓机节奏；矩形相连则和弦无缝衔接，不相连则断开；
混响与延时强度由房间尺寸决定。启动时有公告弹窗与开始菜单，并循环播放本地 OST。

- 运行方式：双击 `index.html` 在浏览器打开（file:// 协议），无安装、无构建、无网络依赖
- 项目文件：`index.html`（应用本体）、`fonts.css`（内置 IPix 字体）、`IPix.ttf`（字体源文件）、`OST/`（背景音乐）
- 平台：桌面浏览器（Chrome / Edge / Firefox 现代版本），不考虑移动端
- 界面语言：以英文为主；用户指定的中文标签保留（音色名「古典主义 / 现代主义」、轨道名「键盘 / 鼓」、构件窗口与「门 / 窗」）

## 2. 功能需求

### 2.1 绘图画布（中央大画布窗口 FLOOR PLAN）

智能模式（无需切换工具）：

- 空白处拖拽 = 新建矩形（≥3px 才算拖拽；<16×16px 的拖动视为误触丢弃）
- 点击矩形 = 选中；点击空白 = 取消选中
- 拖拽矩形内部 = 移动；拖拽边/角手柄 = 缩放（自由缩放）
- 矩形最小 16×16px，不超出画布边界；移动/缩放中 Esc 取消并还原
- Delete / Backspace 删除选中矩形；Ctrl+Z 撤销（上限 100 步）
- 网格背景（24px + 96px 强调线，仅显示、不吸附）
- 矩形样式 = 建筑平面图：地板填充 + 周围一圈有厚度的墙体（见 docs/03 §4.5）
- 矩形左上角显示创建顺序编号（= 播放顺序）
- 重叠矩形的重叠区域不画墙体（空间互相打通）

### 2.2 和弦系统（C 大调，按矩形数量分配）

| 矩形数 n | 和弦序列（按创建顺序） |
| --- | --- |
| 1 | C |
| 2 | C, G |
| 3 | Dm, G, C |
| 4 | Dm, G, C, Am |
| 5 | C, G, Am, F, Em |
| 6 | Am, C, G, D, F, Em |
| 7 | C, G, Am, Em, F, C, Dm |
| 8 | C, G, Am, Em, F, C, F, G（卡农进行） |
| >8 | 卡农进行循环，不再新增和弦 |

- 删除矩形后 n 变化 → 全部矩形的和弦重新计算（基于数量）
- 和弦的具体名称不向用户展示（界面任何位置不显示和弦名）

### 2.3 连接性与乐句

- 相邻两矩形（按创建顺序）共边（±2px 容差）或重叠 = 连接 → 两和弦无缝衔接（legato）
- 不相连 → 上一个和弦提前 1 拍收尾、留 0.5 拍停顿，再起下一个（可听见断开）
- 仅角相触不算连接
- 矩形重叠时，重叠区域的墙体自动去除

### 2.4 播放

- PLAY 键 = 按创建顺序**循环播放**全部矩形的和弦（不按 STOP 就一直循环）；播放中按钮变 STOP，按下立即停止（含正在响的和弦）；Esc / Space 亦可停止
- 循环衔接永远无缝（无停顿）；奇数个矩形时最后重复一遍末和弦、凑成偶数次再接入下一循环（重复和弦与原末和弦之间也无缝衔接）
- 每和弦占 1 小节（4 拍）槽位，起点与节拍器重音严格对齐
- BPM 滑杆（60–200，默认 120）：控制速度；播放中调节时当前遍保持旧速、下一遍生效；延时时间实时跟随 BPM
- 节拍器开关（METRO）：仅播放时响（电子哔声，每小节第一拍 1320Hz 高音强调，其余 880Hz）；播放中启动会对齐到当前循环网格，从当前拍继续
- 键盘轨道（TRACKS 窗口「键盘」）：音量滑块（0–100，默认 100，**立即生效**）缩放和弦电平；M 静音键**立即静音**（已排程和弦即刻停止、回声尾掐掉），高亮巡游与节拍器照常（时间网格保留，鼓轨道共用）；取消静音后从下一个和弦槽位恢复发声
- 播放中高亮当前发声的矩形（酸绿描边）
- 0 个矩形时按 PLAY 不启动
- 播放中编辑画布不影响本次播放（按播放瞬间快照演奏）
- 主音量滑杆（TRANSPORT 窗口 VOL，默认 70%，立即生效）

### 2.5 音色（当前代码参数）

- 两种可切换音色（TIMBRE 窗口）：
  - **古典主义**（默认）：PAD 软音色——saw×2 ±7 cents + triangle 低八度；attack 0.3s、sustain 1.0、lowpass 900Hz + 呼吸 LFO（0.3Hz ±120Hz）；混响系数 1.0
  - **现代主义**：80s 合成器 KEY 音色——square（+24 cents）+ triangle（−12 cents）+ square + 高八度 triangle 四层；attack 0.02s、sustain 0.1、decay 0.1、lowpass 3300Hz、LFO 5Hz ±3Hz；混响系数 0.9
- 两种音色同样演奏和弦与进行；播放中切换从下一遍循环生效
- 混响/延时强度由矩形尺寸决定（取短边 min(w,h)）：≤36px 完全无混响/延时；≥240px 拉满（混响 wet 1.0 × 音色系数、延时发送 0.8）；中间线性过渡
- delay 为 BPM 同步的附点八分回声，反馈 0.3（不强）

### 2.6 信息面板

- 顶部信息栏：等宽状态文本（READY / SPACE 02 SELECTED / PLAYING）+ 闪烁状态块
- 左侧栏（竖向三窗口）：
  - 上：「ARCHISONIC」项目名（IPix 像素字体，加粗，略下沉居中于暖灰方框）
  - 中：TRACKS 轨道窗口（键盘 / 鼓 两个轨道头：音量滑块 + M 静音键；鼓 = 门窗生成的鼓机节奏）
  - 下：TIMBRE 音色选择窗口（古典主义 / 现代主义）
- 底部面板（横向四窗口）：
  - TRANSPORT：VOLUME 滑杆、BPM 滑杆（60–200）、METRO 节拍器开关、KEY: C MAJOR、AUDIO: STANDBY/READY 状态读数
  - PLAYER：三角形 PLAY 按钮（播放中变方块 STOP）；窗口内不显示任何和弦名称
  - MANUAL：操作提示
  - 构件：门 / 窗 两个工具按钮（选中高亮）
- 底部状态条：SPACES 计数 · KEY: C MAJOR · 状态 · 闪烁块
- 窗口外观：所有窗口 1px --ink 内框 + 1px --acid 外框（box-shadow）；标题条统一 --ink 底
- 画布背景底色：#B5B5B3（中灰）

### 2.7 构件（门 / 窗）

- 底部「构件」窗口两个选项：门、窗（点击选中，再点取消）
- 选中后点击矩形四边 → 在该处墙上打出开口（工具激活时只响应墙边点击）
- 点击画布空白处（或按 Esc）→ 取消构件工具，回到普通模式
- 工具激活时：隐藏选中矩形的缩放框，光标为普通箭头
- 门：较长开口（40px），用窄长灰色门板条（40×10px，#B5B5B3）表示
- 窗：较短开口（26px），打掉墙体后画半透明白条（26×5px，rgba(216,216,214,0.5)）+ 3 条黑色细线（线条平行于墙壁、垂直于墙壁断面）
- 靠墙角点击时开口自动让位：开口边缘与墙角交点至少预留 5px（边太短放不下则忽略）
- 点击已有门窗本身（中心距 ±4px）→ 删除该门窗（可 Ctrl+Z 撤销）
- 不允许两个门窗重叠：新开口会与已有门窗部分重叠 → 点击被忽略、什么都不显示
- 开口随矩形移动 / 缩放 / 删除 / 撤销（Ctrl+Z）
- 被其他房间遮盖（墙被吞掉）的门窗：不显示、不参与鼓声；数据保留，房间移开后自动恢复
  （判定：开口中心点落入其他房间内缩 4px 的区域；共边拼接不误判）
- 门窗的声音接入鼓轨道（见 2.8）

### 2.8 鼓机（16 步音序器）

- 窗 = 擦片（踩镲）：白噪声 highpass 7500Hz 短促"擦"；门 = 底鼓（sine 160→46Hz 扫频）+ 军鼓（噪声 bandpass 1800Hz + triangle 200Hz）同点叠奏
- 16 步 = 每小节 16 分音符；步长 spb/4 随 BPM 实时变化，与节拍器和和弦槽位同网格（第 1 步 = 重音）
- 全部门窗汇总成一个固定节奏（用户拍板）：门 → 强拍位（步 0/8/4/12，第 1/3/2/4 拍）；
  窗 → 弱拍位（步 2/6/10/14 反拍八分，轻重交替 vel 0.65/0.5）；每类最多取 4 个（按创建顺序）
- 鼓声音接入左侧「鼓」轨道：音量滑块即时生效、M 静音键即时静音（网格照常推进）
- 与键盘轨道独立（键盘静音时鼓照常）；STOP 即停；播放开始快照，播放中增删门窗不影响本次

### 2.9 启动流程（公告 + 开始菜单 + OST）

- 打开页面先弹公告弹窗：标题条「ARCHISONIC — ALPHA 1」、主标题「ARCHISONIC: unfinished tour」、
  版本「Alpha 1.0test」、玩法小字介绍、OK 按钮
- 点 OK：关闭公告 → 该点击作为用户手势解锁并开始循环播放本地 OST（规避浏览器自动播放策略）
- 公告下方为 paper 底色开始菜单：大字像素 ARCHISONIC（硬阴影）+ 宽字距 UNFINISHED TOUR + 像素风 LETS DESIGN 按钮
- 点 LETS DESIGN：OST 淡出停止（约 0.6s），进入主界面并顺带解锁应用音频

## 3. 已确认决策（2026-11-10）

v1 产品方案（用户拍板）：

1. PLAY = 顺序播放全部矩形（按创建顺序），相连 legato、不相连有停顿
2. 连接判定 = 共边或重叠（仅角相触不算）
3. 和弦进行按数量分档（用户逐档指定：2=C,G；6/7/8 各有专属进行，8 为卡农）；>8 卡农循环不再新增；循环衔接无缝；奇数个数重复末和弦凑偶数次
4. UI 布局 = 顶部栏 + 左侧栏 + 中央大画布窗口 + 底部横排小窗口
5. 音色命名：古典主义 / 现代主义；轨道命名：键盘 / 鼓；构件命名：门 / 窗
6. 鼓节奏来源：全部门窗汇总固定节奏
7. 门窗：不允许重叠，点击已有可删除；靠角 5px 预留

协作机制：

8. 开发日志：会话驱动（每次开发会话结束由 Claude 自动更新 DEVLOG.md）
9. 版本管理：git（安装于 E:\Git，用完整路径 `E:\Git\cmd\git.exe` 调用），每里程碑/功能完成后提交

## 4. 约束与假设

- 纯前端、本地文件：`index.html` + `fonts.css` + `IPix.ttf` + `OST/`；无框架、无构建、无 CDN、无网络请求、无 ES Module（file:// CORS 限制）
- 声音：应用内所有乐器（和弦、节拍器、鼓）由 Web Audio API 实时合成（含程序化混响脉冲响应）；
  唯一加载的音频文件是本地 OST 背景音乐（`OST/ARCHISONIC- demo-1.mp3`，相对路径，file:// 可用）
- 字体：随项目内置 IPix 像素字体（fonts.css base64 嵌入，任意电脑离线可用）；不使用任何在线 webfont / CDN 字体
- 配色与字体规范见 docs/03-设计规范.md；技术实现细节见 docs/02-技术方案.md
