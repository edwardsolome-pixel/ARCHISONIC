# 01 · 需求规范 — ARCHISONIC: UNFINISHED TOUR

> 状态：v1.0 冻结（2026-11-10，全部关键决策经用户确认）
> 本文档是功能需求的唯一权威来源。实现与本文档冲突时以本文档为准。

## 1. 产品概述

ARCHISONIC: UNFINISHED TOUR 是一款基于网页运行的交互式建筑绘图与生成音乐软件，
面向桌面浏览器。用户在中央画布上通过鼠标拖拽创建矩形（每个矩形 = 一个建筑空间单元），
系统提取其几何数据（位置、宽度、高度、面积、比例）并映射为音乐参数，实时生成和弦与音乐序列。

- 核心概念：画布 = 建筑图纸 = 乐谱；矩形 = 空间 = 一段音乐；画图即作曲
- 运行方式：双击 `index.html` 在浏览器打开（file:// 协议），无安装、无构建、无网络依赖
- 平台：桌面浏览器（Chrome / Edge / Firefox 现代版本），不考虑移动端
- 界面语言：英文（产品气质：复古数字文化、地下电子音乐）

## 2. 功能需求

### 2.1 绘图画布（中央大面积画布）

智能模式（无需切换工具）：

- 空白处拖拽 = 新建矩形（≥3px 才算拖拽；<16×16px 的拖动视为误触丢弃）
- 拖拽矩形内部 = 移动；拖拽边/角手柄 = 缩放（自由缩放）
- 点击矩形 = 选中；点击空白 = 取消选中
- 矩形最小 16×16px，不超出画布边界；移动/缩放中 Esc 取消并还原
- Delete / Backspace 删除选中矩形；Ctrl+Z 撤销（上限 100 步）
- 网格背景（24px，仅显示、不吸附）；矩形左上角显示编号
- 拖拽创建时显示虚线预览 + 实时 W/H 读数

### 2.2 几何 → 音乐映射（预设 + 简单调节）

| 几何数据 | 音乐参数 | 规则 |
| --- | --- | --- |
| x 位置（取矩形中心） | 音高（音阶内） | 画布从左到右 = 音阶从低到高 |
| 宽度 | 时值 | 越宽持续越长（0.25–4 拍，量化到 1/4 拍） |
| 纵向位置 y（取中心，越靠上） | 八度 | 三档：上 1/4 区 +1、中 1/2 区 0、下 1/4 区 −1 |
| 面积 | 音量 | 越大越响（−21 ~ −6 dB 单音） |
| 宽高比 e = 长边/短边 | 和弦类型 | 见下表 |

宽高比 → 和弦分档：

| e 范围 | 和弦 | 构成音（相对根音半音） | 气质 |
| --- | --- | --- | --- |
| 1.00–1.15 | PWR5 | 0,7,12 | 协和稳定（近正方形） |
| 1.15–1.60 | SUS4 | 0,5,7 | 悬浮、开阔 |
| 1.60–2.40 | MIN | 0,3,7 | 阴郁张力 |
| ≥ 2.40 | DIM | 0,3,6 | 刺耳不协和（极端细长） |

- 矩形几何变化后自动试听一次（编辑结束时触发，拖拽过程中不连续发声）
- 调节控件：BPM 60–200（默认 120）、音阶下拉（4 种，默认 C MIN PENTA）、主音量滑杆（默认 70%）

### 2.3 播放

- 点击矩形 = 试听其和弦（芯片琶音：和弦音以 35ms 间隔依次进入，总时长 0.45–0.8s）
- TOUR = 播放头按创建顺序巡游所有矩形、逐个发声；STOP / Esc / Space 停止
- 播放头高亮当前空间 + 沿空间边缘扫过的光点，动画与音频同步
- TOUR 进行中锁定编辑（停止后恢复）；0 个矩形时按 TOUR 不启动

### 2.4 信息面板

- 顶部信息栏：品牌字「ARCHISONIC / UNFINISHED TOUR」、等宽状态文本（READY / SPACE 02 SELECTED / TOUR ▶ SPACE 03/12 / AUDIO: STANDBY）、TOUR / STOP 按钮、闪烁状态块
- 底部面板（横向四窗口）：
  - TRANSPORT：TOUR 大按钮、BPM 滑杆、SCALE 下拉、VOLUME 滑杆、CLEAR 按钮
  - SPACE DATA：X / Y / W / H / AREA / RATIO
  - SONIC MAPPING：PITCH / CHORD / OCT / DUR / VOL（含 ASCII 电平条）
  - MANUAL：快捷键清单
- 底部状态条：SPACES 计数 · 当前音阶 · AUTOSAVE 状态

### 2.5 持久化

- localStorage 自动保存（key：`archisonic.doc.v1`），刷新 / 重开恢复
- 首次运行预置 5 个示例矩形（覆盖各和弦档位，可直接试听与 TOUR）
- CLEAR 清空全部矩形（可 Ctrl+Z 整体撤销）；清空后刷新不重新播种
- 空状态提示：EMPTY LOT. DRAG TO DRAW A RECTANGLE.

## 3. 已确认决策（2026-11-10）

1. 播放方式：点击试听 + TOUR 巡游
2. 画布操作：智能模式
3. 音色：复古芯片音（8-bit 方波，Web Audio 合成）
4. 音乐参数：预设映射 + 简单调节
5. 辅助面板位置：底部横向（用户确认）
6. 开发日志：会话驱动（每次开发会话结束由 Claude 自动更新 DEVLOG.md）
7. 版本管理：每里程碑验收后做文件夹备份（`e:\ARCHISONIC-demo-2-m{n}-backup`）；git 暂未安装，日后可随时切换

## 4. 约束与假设

- 纯前端单文件 index.html，无框架、无构建、无外部依赖、无网络请求、无 ES Module（file:// CORS 限制）
- 声音全部由 Web Audio API 合成，不加载音频文件
- 字体仅用系统字体（Georgia / Courier New），不使用 webfont
- 配色与字体规范见 docs/03-设计规范.md；技术实现细节见 docs/02-技术方案.md
