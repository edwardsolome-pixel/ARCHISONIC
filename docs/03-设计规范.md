# 03 · 设计规范 — ARCHISONIC: UNFINISHED TOUR

> 状态：v2.1（2026-11-10 按用户验收反馈修订：画布底色 #B5B5B3、绿色 TRANSPORT/PLAYER 窗口、
> 左侧栏三窗口、三角 PLAY 键、和弦名称隐藏）。所有视觉实现的唯一标准，色板外颜色一律不允许出现。

## 1. 设计定位

复古计算机操作系统 × 早期数字音乐软件 × 像素游戏界面。
关键词：复古数字文化、地下电子音乐、克制、模块化、机读感。

## 2. 色板

| 变量 | 值 | 用途 |
| --- | --- | --- |
| --paper | #D8D8D6 | 模块窗口底色、矩形地板填充、浅底上的主文字 |
| --gray | #B5B5B3 | **画布背景底色（用户指定）**、次级描边、墙体内侧分界线、次级文字 |
| --ink | #525252 | 页面背景、标题条、墙体、按钮文字、描边、主文字（2026-11-10 用户调整） |
| --acid | #B8E83E | 强调：选中态、播放高亮、绿色窗口（标题条/边框）、三角 PLAY 键、编号、状态指示 |
| 网格线(小) | rgba(48,48,48,0.10) | 仅画布 24px 网格（浅底上深线） |
| 网格线(大) | rgba(48,48,48,0.22) | 仅画布 96px 强调网格 |
| 扫描线 | rgba(0,0,0,0.03) | 全屏装饰覆盖层 |

规则：--acid 用于「当前正在发生的事」（选中/播放/激活）+ 用户指定的常驻元素
（TRANSPORT/PLAYER 窗口、三角 PLAY 键、编号）；其余大面积留灰。

## 3. 字体

| 角色 | 字体 | 字号/样式 |
| --- | --- | --- |
| 项目名 ARCHISONIC | IPix | 20px，加粗，字距 2px |
| 窗口标题 / 数据 / 状态 / 按钮 | IPix | 11–12px，全大写，letter-spacing 0.08em |
| 画布编号 / 小标签 | IPix | 10–11px |

全站字体统一为用户本机安装的像素字体 **IPix**（IPix中文像素字体.ttf，用户级安装，2026-11-10 用户指定）；
缺字体环境回退 monospace。所有界面文案全大写 + 统一字距（复古机读感）。不使用任何 webfont（IPix 为本地字体，离线可用）。

## 4. 组件规范

### 4.1 模块化窗口（.window）

- 标题条：24px 高，--ink 底、--paper 等宽字；FLOOR PLAN 窗口标题条含假按钮 [–][□][×]
- 边框：内圈 1px --ink + 外圈 1px --acid（box-shadow；用户指定全部窗口酸绿外框）
- 绿色窗口变体 .win-acid（TRANSPORT、PLAYER）：语义类（全部窗口外框已统一为酸绿）
- 像素角（8×8px L 形 --acid）：仅 FLOOR PLAN 主窗口四角

### 4.2 按钮

- **三角 PLAY 键（用户指定）**：--ink 底三角形（clip-path，右指），约 32×30px（用户调整）；
  hover --paper 底；active --ink 底；播放中变方块 STOP（56×56px，--acid 底 --ink 字）；
  位于 PLAYER 窗口 paper 方框中，略下沉居中
- 默认按钮：--paper 底、1px --ink 边框、--ink 字；hover --gray 底；active 下移 1px
- 音色选择按钮（TIMBRE 窗口）：竖排通栏，选中态 --acid 底 --ink 字（.btn-on）；文字为中文音色名（用户指定，IPix 中文像素字体渲染）
- 静音键（TRACKS 轨道头）：24×24px 小方键 "M"，静音中 --acid 底（.btn-on 复用）；轨道行 = [中文名（键盘/鼓）][窄滑块 70px][M 键]，行间距 8px
- 等宽字、全大写、letter-spacing 0.08em（中文音色名除外）

### 4.3 滑杆

- 轨道：2px --ink 线；滑块：10×14px --ink 矩形；拖拽中（:active）--acid
- 旁标 10px 等宽读数

### 4.4 画布

- 背景 --gray（#B5B5B3，用户指定）；24px 小网格 + 96px 强调网格（深色线，见 §2）

### 4.5 平面图矩形（v1 核心视觉）

绘制顺序（由外到内）：

1. 地板：填充 --paper（暖灰）
2. 墙体：8px 描边 --ink（深炭灰，浅底上对比清晰）
3. 墙体内侧分界线：1px 描边 --gray（贴墙体内缘）
4. 编号：11px 等宽 --acid，矩形内左上角；w<28 或 h<18 时跳过
5. 选中态：2px --acid 描边（矩形外缘）+ 8 个 7×7px --acid 手柄（1px --ink 内边）
6. 播放高亮（M3）：当前发声矩形 2px --acid 描边 + 轻微闪烁
7. 橡皮筋（创建中）：2px 虚线 --acid + 光标旁 W/H 等宽标注
8. 构件开口（绘制于选中态之上）：
   - 门：40px 长 × 10px 宽灰色板条（#B5B5B3），沿墙方向覆盖墙体（墙洞）
   - 窗：先以画布底色（--gray）打掉 26×8 墙体，再画 26×14 半透明白块 rgba(216,216,214,0.75) + 3 条 1px #303030 细线平分四格窗扇（线垂直于墙）

### 4.6 状态元素

- 顶栏状态文本：等宽 12px（READY / SPACE 02 SELECTED / PLAYING / AUDIO: STANDBY）
- 闪烁块 █：8×8px --acid，steps 动画 1s 周期（顶栏与状态条各一）
- 空状态浮层：居中等宽 14px 深灰（浅底上）闪烁（2s 周期）+ 副行 11px 提示

### 4.7 装饰层

- 全屏扫描线：repeating-linear-gradient 横向细纹 rgba(0,0,0,0.03)，pointer-events:none，覆盖全屏

## 5. 布局（2026-11-10 修订）

- 顶栏 44px：状态文本 + 闪烁块，居中
- 中部：左侧栏 190px（竖向三窗口：上「ARCHISONIC」64px 非衬线、略下沉居中于 paper 方框 / 中 TRACKS 轨道头（键盘·鼓）/ 下 TIMBRE 音色选择）+ FLOOR PLAN 窗口 flex:1（canvas 铺满，min-height 420px）
- 底部面板：TRANSPORT 240px（绿色）/ PLAYER 220px（绿色，只放三角 PLAY 键，不显示任何和弦名）/ MANUAL 自适应 / 构件 110px（门·窗工具按钮，选中 .btn-on 高亮）；<1100px 折两行
- 状态条 22px（--ink 底 --gray 等宽小字）
- 断点：<1100px 左侧栏缩至 150px；body min-width 720px
- 最小可用窗口 1000×640
