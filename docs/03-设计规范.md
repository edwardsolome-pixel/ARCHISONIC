# 03 · 设计规范 — ARCHISONIC: UNFINISHED TOUR

> 状态：v2.0（2026-11-10）。所有视觉实现的唯一标准。色板外颜色一律不允许出现。

## 1. 设计定位

复古计算机操作系统 × 早期数字音乐软件 × 像素游戏界面。
关键词：复古数字文化、地下电子音乐、克制、模块化、机读感。

## 2. 色板

| 变量 | 值 | 用途 |
| --- | --- | --- |
| --paper | #D8D8D6 | 模块窗口底色、矩形地板填充、浅底上的主文字 |
| --gray | #B5B5B3 | 次级边框/描边、墙体、次级文字 |
| --ink | #303030 | 页面背景、画布背景、标题条、按钮文字、描边 |
| --acid | #B8E83E | 强调：选中态、播放高亮、主按钮、编号、状态指示 |
| 网格线(小) | rgba(216,216,214,0.08) | 仅画布 24px 网格 |
| 网格线(大) | rgba(216,216,214,0.18) | 仅画布 96px 强调网格 |
| 扫描线 | rgba(0,0,0,0.03) | 全屏装饰覆盖层 |

规则：--acid 每次只用于「当前正在发生的事」（选中 / 播放 / 激活 / 主行动按钮 / 编号）；大面积留灰。

## 3. 字体

| 角色 | 字体 | 字号/样式 |
| --- | --- | --- |
| 品牌 ARCHISONIC | Georgia, serif | 22px，斜体 |
| 副题 / 窗口标题 | 'Courier New', monospace | 12px，全大写，letter-spacing 0.08em |
| 数据读数 / 状态 / 按钮 | 'Courier New', monospace | 12px |
| 画布编号 / 小标签 | 'Courier New', monospace | 10–11px |

所有界面文案全大写 + 统一字距（复古机读感）。不使用任何 webfont。

## 4. 组件规范

### 4.1 模块化窗口（.window）

- 标题条：24px 高，--ink 底、--paper 等宽字；FLOOR PLAN 窗口标题条含假按钮 [–][□][×]
- 边框：内圈 1px --ink + 外圈 1px --gray（box-shadow 叠加法）
- 像素角（8×8px L 形）：FLOOR PLAN 主窗口四角用 --acid；底部三个小窗口不用像素角（保持克制）

### 4.2 按钮

- 主按钮 PLAY：--acid 底、--ink 字、2px --ink 边框、28px 高；播放中变 STOP；hover --paper 底；active 下移 1px
- 默认按钮：--paper 底、1px --ink 边框、--ink 字；hover --gray 底；active 下移 1px
- 等宽字、全大写、letter-spacing 0.08em

### 4.3 滑杆

- 轨道：2px --ink 线；滑块：10×14px --ink 矩形；拖拽中（:active）--acid
- 旁标 10px 等宽读数（如 `70`）

### 4.4 画布

- 背景 --ink；24px 小网格 + 96px 强调网格
- 网格外：FLOOR PLAN 窗口内容区即为画布，铺满

### 4.5 平面图矩形（v1 核心视觉）

绘制顺序（由外到内）：

1. 墙体：8px 描边 --gray（中灰，与深底有对比）
2. 地板：填充 --paper（暖灰）
3. 墙体内侧分界线：1px 描边 --ink（贴着地板外缘，位于墙体宽度内缘）
4. 编号：11px 等宽 --acid，矩形内左上角 3px；w<28 或 h<18 时跳过
5. 选中态：2px --acid 描边（矩形外缘）+ 8 个 7×7px --acid 手柄（1px --ink 内边）
6. 播放高亮：当前发声矩形 2px --acid 描边 + 轻微闪烁
7. 橡皮筋（创建中）：2px 虚线 --acid + 光标旁 W/H 等宽标注

### 4.6 状态元素

- 顶栏状态文本：等宽 12px（READY / PLAYING / AUDIO: STANDBY / AUDIO: READY）
- 闪烁块 █：8×8px --acid，steps 动画 1s 周期（顶栏与状态条各一）
- 空状态浮层：居中等宽 14px --gray 闪烁（2s 周期）+ 副行 11px 提示

### 4.7 装饰层

- 全屏扫描线：repeating-linear-gradient 横向细纹 rgba(0,0,0,0.03)，pointer-events:none，覆盖全屏

## 5. 布局

- 顶栏 44px ｜ 舞台 flex:1（内边距 12px；FLOOR PLAN 窗口铺满；canvas min-height 420px）
- 底部面板：TRANSPORT 240px / CHORDS 220px / MANUAL 自适应，三窗口横排，窗口间 8px 间距
- 状态条 22px（--ink 底 --gray 等宽小字）
- 断点：<1100px 底部窗口折两行；body min-width 720px
- 最小可用窗口 1000×640
