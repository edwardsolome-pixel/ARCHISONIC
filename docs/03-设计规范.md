# 03 · 设计规范 — ARCHISONIC: UNFINISHED TOUR

> 状态：v1.0（2026-11-10）。所有视觉实现的唯一标准。色板外颜色一律不允许出现。

## 1. 设计定位

复古计算机操作系统 × 早期数字音乐软件 × 像素游戏界面。
关键词：复古数字文化、地下电子音乐、克制、模块化、机读感。

## 2. 色板

| 变量 | 值 | 用途 |
| --- | --- | --- |
| --paper | #D8D8D6 | 模块窗口底色、矩形填充、浅底上的主文字 |
| --gray | #B5B5B3 | 次级边框/描边、次级文字 |
| --ink | #303030 | 页面背景、画布背景、标题条、按钮文字、描边 |
| --acid | #B8E83E | 强调：选中态、播放头、主按钮、激活读数 |
| 网格线(小) | rgba(216,216,214,0.08) | 仅画布 24px 网格 |
| 网格线(大) | rgba(216,216,214,0.18) | 仅画布 96px 强调网格 |
| 扫描线 | rgba(0,0,0,0.03) | 全屏装饰覆盖层 |

规则：--acid 每次只用于「当前正在发生的事」（选中 / 播放 / 激活 / 主行动按钮）；大面积留灰。

## 3. 字体

| 角色 | 字体 | 字号/样式 |
| --- | --- | --- |
| 品牌 ARCHISONIC | Georgia, serif | 22px，斜体 |
| 副题 / 窗口标题 | 'Courier New', monospace | 12px，全大写，letter-spacing 0.08em |
| 数据读数 / 状态 / 按钮 | 'Courier New', monospace | 12px |
| 画布编号 / 小标签 | 'Courier New', monospace | 10–11px |

所有界面文案全大写 + 统一字距（复古机读感）。不使用任何 webfont。

## 4. 组件规范

### 4.1 模块化窗口（.window，四个面板共用）

- 标题条：24px 高，--ink 底、--paper 等宽字；舞台窗口标题条含假按钮 [–][□][×]
- 边框：内圈 1px --ink + 外圈 1px --gray（box-shadow 叠加法）
- 四角像素角：8×8px L 形 --acid 块（::before/::after + 子 div）

### 4.2 按钮

- 默认：--paper 底、1px --ink 边框、--ink 字；hover --gray 底；active 下移 1px
- 主按钮 TOUR：--acid 底、--ink 字、2px --ink 边框；播放中变 STOP；hover 反色
- 危险按钮 CLEAR：--ink 底、--gray 字；hover 反色
- 高 24px，padding 0 12px，等宽字

### 4.3 滑杆

- 轨道：2px --ink 线；滑块：10×14px --ink 矩形，拖拽中 --acid
- 旁标 10px 等宽读数（如 `120 BPM`）

### 4.4 下拉框

- 原生 select 重置：appearance:none、--paper 底、1px --ink 边框、等宽字、自绘箭头三角

### 4.5 画布

- 背景 --ink；24px 小网格 + 96px 强调网格（见 §2）
- 矩形：填充 --paper(α0.95)、2px --ink 描边
- 选中：2px --acid 描边 + 8 个 7×7px --acid 手柄（1px --ink 内边）
- TOUR 当前：--acid α0.30 叠加 + 3px --acid 扫掠光点（shadowBlur 8）
- 编号：11px 等宽 --acid，矩形内左上角 3px；小矩形跳过；TOUR 态翻 --ink
- 橡皮筋：2px --acid 虚线 + 光标旁 W/H 等宽标注
- 空状态：居中等宽 14px --gray，2s 周期闪烁

### 4.6 状态元素

- 顶栏状态文本：等宽 12px（READY / TOUR ▶ SPACE 03/12 / AUDIO: STANDBY）
- 闪烁块 █：8×8px --acid，steps 动画 1s 周期
- 音量电平条：ASCII ▓▓▓░░░░（SONIC MAPPING 内）

### 4.7 数据表格（READOUT）

- 两列等宽 12px：左标签 --gray，右数值 --ink；选中态数值 --acid
- 行高 18px；未选中显示 NO SPACE SELECTED

### 4.8 装饰层

- 全屏扫描线：repeating-linear-gradient 横向细纹 α0.03，pointer-events:none

## 5. 布局

- 顶栏 44px ｜ 舞台 flex:1（内边距 12px，canvas 铺满窗口内区，min-height 420px）
- 底部面板 ~140px：TRANSPORT 280px / SPACE DATA 240px / SONIC MAPPING 240px / MANUAL 自适应
- 底部状态条 22px（--ink 底 --gray 字）
- 断点：<1100px 底部四窗口折两行；body min-width 720px
- 最小可用窗口 1000×640
