# 03 · 设计规范 — ARCHISONIC: UNFINISHED TOUR

> 状态：v3.0（2026-11-11 全量核对：与 index.html 实际样式比对并修订——字体统一 IPix、
> 轨道滑块 110px、播放键绝对居中、窗白条 5px/0.5、播放高亮无闪烁、新增公告与开始菜单规范）。
> 所有视觉实现的唯一标准，色板外颜色一律不允许出现。

## 1. 设计定位

复古计算机操作系统 × 早期数字音乐软件 × 像素游戏界面。
关键词：复古数字文化、地下电子音乐、克制、模块化、机读感。

## 2. 色板

| 变量 | 值 | 用途 |
| --- | --- | --- |
| --paper | #D8D8D6 | 模块窗口底色、矩形地板填充、浅底上的主文字 |
| --gray | #B5B5B3 | 画布背景底色、次级描边、墙体内侧分界线、门板条、次级文字 |
| --ink | #525252 | 页面背景、标题条、墙体、按钮文字、描边、主文字 |
| --acid | #B8E83E | 强调：选中态、播放高亮、所有窗口外框、三角 PLAY 键、编号、状态指示、激活按钮 |
| 网格线(小) | rgba(48,48,48,0.10) | 仅画布 24px 网格（浅底上深线） |
| 网格线(大) | rgba(48,48,48,0.22) | 仅画布 96px 强调网格 |
| 扫描线 | rgba(0,0,0,0.03) | 全屏装饰覆盖层 |
| 公告遮罩 | rgba(48,48,48,0.6) | 公告弹窗背景 |

规则：--acid 用于「当前正在发生的事」（选中/播放/激活）+ 用户指定的常驻元素
（窗口外框、三角 PLAY 键、编号）；其余大面积留灰。

## 3. 字体

| 角色 | 字体 | 字号/样式 |
| --- | --- | --- |
| 项目名 ARCHISONIC（左侧栏） | IPix | 20px，加粗，字距 2px |
| 开始菜单标题 | IPix | 64px，字距 4px，硬阴影 4px 4px 0 --gray |
| 开始菜单副题 | IPix | 16px，字距 0.5em |
| 公告主标题 / 版本 | IPix | 22px / 12px（版本字距 0.3em） |
| 窗口标题 / 数据 / 状态 / 按钮 | IPix | 11–12px，全大写，letter-spacing 0.08em |
| 画布编号 / 小标签 | IPix | 11px |

- 全站字体统一为像素字体 **IPix**（用户指定）。字体随项目内置：fonts.css 以 @font-face + base64
  data URI 嵌入（任意电脑双击打开即生效；file:// 下直接引用 .ttf 会被浏览器 CORS 拦截）；
  源文件 IPix.ttf 存放于项目根目录。缺字体环境回退 monospace。
- 例外：画布橡皮筋的 W/H 尺寸标注在代码中使用 `11px "Courier New"`（保持现状，勿擅自改动）。
- 界面文案以英文为主 + 全大写 + 统一字距；用户指定的中文标签（古典主义/现代主义、键盘/鼓、构件、门/窗）除外。

## 4. 组件规范

### 4.1 模块化窗口（.window）

- 背景 --paper；边框：内圈 1px --ink + 外圈 1px --acid（box-shadow，全部窗口统一）
- 标题条：24px 高，--ink 底、--paper 等宽字；FLOOR PLAN 窗口标题条含假按钮 [–][□][×]
- 绿色窗口变体 .win-acid（TRANSPORT、PLAYER）：仅保留语义类，标题条与其他窗口一致（--ink 底）
- 像素角（8×8px L 形 --acid）：仅 FLOOR PLAN 主窗口四角

### 4.2 按钮

- **三角 PLAY 键**：绝对定位居中于 PLAYER 窗口（player-body 固定高 56px，中心距 body 顶 65px）；
  --ink 底三角形（clip-path 右指，32×30px）；hover --paper 底；active --ink 底；
  播放中变方块 STOP（56×56px，--acid 底 --ink 字，文字 "STOP"）；两种状态中心点完全重合
- 默认按钮：--paper 底、1px --ink 边框、--ink 字；hover --gray 底；active 下移 1px
- 音色选择按钮（TIMBRE）：竖排通栏，选中态 --acid 底 --ink 字（.btn-on）；文字为中文音色名
- 构件按钮（构件窗口）：竖排通栏，选中态 .btn-on 高亮；文字「门」「窗」
- 静音键（TRACKS 轨道头）：24×24px 小方键 "M"，静音中 --acid 底（.btn-on）；
  轨道行 = [中文名 32px 固定宽][滑块 110px][M 键]，行间距 8px
- 开始菜单 LETS DESIGN：--acid 底 --ink 字，3px --ink 边框，20px 字 / 字距 0.2em，
  padding 14×28，硬阴影 6px 6px 0 --gray；hover --paper 底；active 位移 (3px,3px)
- 公告 OK：默认主按钮样式（btn-acid：--acid 底 + 2px --ink 边框）

### 4.3 滑杆

- 轨道：2px --ink 线；滑块：10×14px --ink 矩形；拖拽中（:active）--acid
- 旁标 10px 等宽读数；TRANSPORT 滑杆宽 120px，TRACKS 轨道滑杆宽 110px

### 4.4 画布

- 背景 --gray（#B5B5B3）；24px 小网格 + 96px 强调网格（深色线，见 §2）

### 4.5 平面图矩形与构件

绘制顺序（由外到内 / 由下到上）：

1. 地板：填充 --paper（暖灰）
2. 墙体：8px 描边 --ink；用 evenodd 裁剪排除其他矩形区域（重叠处不画墙）
3. 墙体内侧分界线：1px 描边 --gray（贴墙体内缘）
4. 编号：11px IPix --acid，位于左上角、自墙体内缘再内缩 2px；w<28 或 h<18 时跳过
5. 选中态：2px --acid 描边（矩形外缘）+ 8 个 7×7px --acid 手柄（1px --ink 内边）
6. 橡皮筋（创建中）：2px 虚线 --acid + 光标旁 W/H 等宽标注
7. 构件开口（绘制于选中态之后、播放高亮之前）：
   - 门：40px 长 × 10px 宽灰色板条（--gray），覆盖墙体（墙洞）
   - 窗：先以画布底色（--gray）打掉 26×8 墙体，再画 26×5 半透明白条 rgba(216,216,214,0.5)
     （位于墙体中线一侧），最后 3 条 1px #303030 细线（平行于墙、垂直于墙壁断面，间距 3.5px）；
     开口距墙角交点至少 5px 预留
8. 播放高亮：当前发声矩形 2px --acid 描边（静态，无闪烁）

### 4.6 状态元素

- 顶栏状态文本：12px（READY / SPACE 02 SELECTED / PLAYING）
- TRANSPORT 面板状态读数：KEY: C MAJOR、AUDIO: STANDBY / AUDIO: READY
- 闪烁块 █：8×8px --acid，steps 动画 1s 周期（顶栏与状态条各一，状态条 6×6px）
- 空状态浮层：居中等宽 14px 深灰（浅底上）闪烁（2s 周期）+ 副行 11px 提示

### 4.7 装饰层

- 全屏扫描线：repeating-linear-gradient 横向细纹 rgba(0,0,0,0.03)，pointer-events:none，覆盖全屏（z-index 9999）

### 4.8 公告与开始菜单

- 公告 #announce：全屏遮罩 rgba(48,48,48,0.6)，居中 420px 模块窗口（max-width 90%）；
  标题条「ARCHISONIC — ALPHA 1」；主标题「ARCHISONIC: unfinished tour」22px --ink；
  版本「Alpha 1.0test」12px 字距 0.3em --ink；玩法说明 12px / 行高 1.9 居中；OK 按钮
- 开始菜单 #startMenu：paper 底色全覆盖；内容垂直居中，元素间距 14px

## 5. 布局

- 顶栏 44px：状态文本 + 闪烁块，居中
- 中部：左侧栏 190px（上「ARCHISONIC」窗口 64px 固定高 / 中 TRACKS 轨道头（键盘·鼓）/ 下 TIMBRE 音色选择）
  + FLOOR PLAN 窗口 flex:1（canvas 铺满，min-height 420px）
- 底部面板：TRANSPORT 240px / PLAYER 220px / MANUAL 自适应 / 构件 110px，四窗口横排（各 min-height 96px）；
  <1100px 折两行
- 状态条 22px（--ink 底 --gray 等宽小字）
- 断点：<1100px 左侧栏缩至 150px；body min-width 720px
- 最小可用窗口 1000×640
- 层级：画布/界面 < 开始菜单(100) < 公告(200) < 扫描线(9999，纯装饰不拦截事件)
