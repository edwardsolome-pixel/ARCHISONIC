> 状态：v0.1 规划稿（2026-11-11）。

## 1. 总目标

1. **音乐生成机制升级**：和弦行进摆脱固定表与机械循环；鼓组具备律动与无极复杂度
2. **四种音乐语言**：古典主义 / 现代主义 / 粗野主义 / 高技派 在听感上高度可辨识
3. **音色可编辑**：宏参数 + 风格专属参数，支撑后续新风格
4. **建筑空间展示**：先做 Canvas 2D 剖视轴测，后续评估室内漫游与外观贴图

**已确认决策（2026-11-11 用户拍板）**

- 允许将 MIT 开源库文件内置进项目（离线随包分发，运行时零网络）
- 和弦种子由建筑布局生成；同一设计的种子不保证相同；**不提供重掷按钮**，
  只能通过修改布局获得新的和弦组合
- 建筑视角先走 **Canvas 2D 剖视轴测**
- 和声允许**转调**；四种音色对应四种曲风，必须辨识度足够

## 2. 现状诊断

| 项目 | 现状 | 问题 |
| --- | --- | --- |
| 和弦 | 按矩形数量查固定表（1–8 档，8=卡农，>8 循环） | 组合单一、无色彩和弦、无转调、无乐句句法 |

## 3. 四种音乐语言总表（核心设计）

> 音色不只是声音，而是整套「音乐语言」：BPM、和声、节奏、鼓、效果、演奏法。
> 切换音色 = 切换整套语言，保证盲听可辨。

| 维度 | 古典主义 · Ambient | 现代主义 · House | 粗野主义 · Techno | 高技派 · Glitch |
| --- | --- | --- | --- | --- |
| 曲风 | 氛围 / 环境音乐 | 浩室 | 科技舞曲 | 故障 / 实验电子 |
| BPM | 60–80 | 118–126 | 130–150 | 100–140（可自由/半速） |
| 调性 | 大调/调式为主，缓慢游移 | 大调/小调，功能清晰 | 小调为主，阴暗 | 任意，可微分音/音簇 |
| 和声语汇 | 挂留、加九、大七、调式色彩 | 七/九和弦、ii–V–I、vi–IV–I–V | i–bVII–bVI 静态循环、强力和弦 | 碎片化、和弦切片、偶然组合 |
| 转调 | 少而缓，±2/±5 半音 | 段落间转调 | 极少或固定 | 随机微转调/失谐 |
| 和弦节奏 | 长音铺底（2–4 小节） | 反拍短和弦 stab | 每拍/切分重复 riff | 不规则触发、口吃 |
| 鼓组 | 无鼓或极稀疏（心跳/低频脉冲） | 四踩底鼓 + 反拍开镲 + 军鼓 2/4 | 硬 kick + 金属打击 + 工业噪声 | 切碎鼓组、随机门限、错位 |
| 效果 | 长混响、长延迟、chorus | 侧链、短混响、滤波包络 | 失真、共振滤波、长延迟 | bitcrush、stutter、颗粒化、随机声像 |
| 空间联想 | 空旷大厅、回声 | 夜店、律动空间 | 混凝土厂房、工业 | 数字故障、机械穿插 |

**转调规则（A5）**

- 允许段内转调；优先 ±2（全音）与 ±5（四度）半音，听觉最自然
- 转调点必须落在乐句边界（4/8 小节）；由布局种子决定，不提供手动按钮
- Ambient 转调最少（可能整曲不转）；House 以段落转调为主；Techno 可长期不转；
  Glitch 允许微小失谐与偶发转调

## 4. 模块 A：和声与进行系统（最高优先级）

### A1 和弦库扩展

- 基础三和弦之外加入：大七 maj7、小七 m7、属七 dom7、挂留 sus2/sus4、加九 add9、
  六和弦 6、九和弦 9、半减 m7b5、减 dim
- 借用和弦：bVII、iv、bVI、bIII（小调借用）
- 副属和弦：V/V、V/vi 等（House 常用）
- 每种风格维护**可用和弦集**（风格越克制，集合越小）：
  - Ambient：maj7 / add9 / sus2 / sus4 / 6，少用属功能
  - House：maj7 / m7 / dom7 / 9 / sus4 + 副属
  - Techno：m / m7 / 强力和弦 / bVII / bVI，几乎不用大七
  - Glitch：全集合 + 音簇/不协和音程，允许无调性片段

### A2 句法生成（替代「数量查表」）

- 以 **4/8 小节乐句**为单位生成，而不是按矩形数量硬查表
- 生成约束：功能进行（主 → 下属 → 属 → 主）+ 模板 + 受控随机
- 风格模板库（示例）：
  - Ambient：I – vi – IV – I（长音）、Imaj7 – IVmaj7 循环、调式漂移
  - House：ii–V–I、vi–IV–I–V、I–vi–ii–V、IV–V–iii–vi
  - Techno：i – bVII – bVI – bVII（2 小节 riff）、单和弦 + 微变
  - Glitch：模板 + 随机替换/插入/删除和弦事件
- 每个乐句带「能量弧线」：句首稳定、句中发展、句尾解决或悬念

### A3 3/5/6/7 与循环问题的解决方案

1. **先句法后映射**：先生成 4/8 小节乐句 → 再把和弦按顺序分配给矩形；
   矩形数少于乐句长度时取乐句前 N 个和弦（保留句法感）；多于时继续展开/变奏
2. **回转和弦**：奇数结尾不再机械重复末和弦，而是插入「回转和弦」
   （如首和弦的 V7 或 viio），让句尾自然导向句首
3. **循环演进**：每 2–4 遍循环自动微调（转位、加音、鼓加花、力度变化），
   避免长时间听觉疲劳（不改变种子，属于「演奏演绎」层）
4. **避免同和弦反复**：约束相邻和弦不得完全相同（除非风格要求，如 Techno 静态循环）

### A4 种子规则（用户指定）

- 种子 = 布局指纹（矩形位置/尺寸/门窗数量与位置 + 会话盐）→ 哈希
- **布局变更 → 种子变化 → 和弦组合变化**；无「重新生成」按钮
- 同一设计在不同会话中种子不保证相同（不承诺严格复现）
- 布局指纹只取结构化数据，不依赖时间戳，避免每次播放都突变

### A5 转调

- 按风格控制转调频率与幅度（见 §3 转调规则）
- 转调点对齐乐句边界；转调前后保持共同音/平滑低音进行

### A6 验收标准

- 3 / 5 / 6 / 7 个矩形连续听 3 遍循环，无明显机械重复、无句尾断裂感
- 四种风格盲听可区分（和弦语汇层面）
- 转调自然、不突兀；修改布局后和弦组合随之变化
- 删除/新增矩形后无需手动操作，播放即按新组合生成

## 5. 模块 B：鼓组与律动（次高优先级）

### B1 声部扩展

kick / snare / clap / closed hat / open hat / tom / perc（金属噪声），
每声部有独立增益与声像；沿用现有 808 风格纯合成思路，新增金属打击（FM/噪声+带通）。

### B2 生成方式

- 16 步网格 + 以下机制：
  - **Euclidean 节奏**：E(k,n) 生成均匀分布的节奏型（适合 hat/tom/perc）
  - **概率门限**：按复杂度对弱拍音符做概率触发
  - **Swing / 微时序**：偶数步延后 5–15%，产生摇摆感
  - **力度层次**：accent / normal / ghost 三档（velocity 0.9 / 0.6 / 0.3）
- 风格鼓型模板：
  - Ambient：几乎无鼓；可选低频脉冲 + 稀疏金属点
  - House：四踩 kick + 2/4 snare/clap + 反拍 open hat + 16 分 closed hat
  - Techno：硬 kick + 金属 perc + 工业噪声 + 长延迟
  - Glitch：切碎/错位/随机门限，鼓组本身成为节奏噪点

### B3 无极复杂度滑块（0–100）

- 0 = 仅骨架（kick + 反拍），100 = 满编（所有声部 + 加花 + 高密度）
- 映射维度：声部层数（连续启用）、音符密度（概率）、加花频率、力度动态、时序人性化程度
- 滑块实时生效（下一小节边界应用，避免切碎当前小节）；默认值按风格预设
- UI：TRANSPORT 或新窗口中的复古滑杆（沿用像素 UI）

### B4 门窗 → 鼓的映射升级

- 门：影响强拍骨架（kick/snare）——数量决定骨架复杂度（1–4 级）
- 窗：影响 16 分/反拍装饰层（hat/perc）——数量决定密度
- 在风格允许范围内映射（如 Ambient 门窗再多也只出稀疏鼓点）
- 保持既有规则：播放开始快照；鼓静音/音量即时生效；STOP 即停

### B5 验收标准

- 四种风格鼓型盲听可辨；复杂度 0→100 连续变化无断层、无爆音
- 门窗数量变化能听出骨架/装饰层差异
- 与和弦/节拍器保持同网格；BPM 实时跟随

## 6. 模块 C：音色与风格引擎

### C1 风格预设重构

把「音色」升级为「风格预设」，每个预设包含：
- 音色参数（振荡器/包络/滤波/效果链）
- 和声集与进行模板（模块 A）
- 鼓型模板与复杂度默认值（模块 B）
- 默认 BPM 区间与转调策略

### C2 新增两种风格

- **粗野主义 · Techno**：锯齿/方波重失真、共振低通扫频、硬 kick、金属 perc、
  长延迟、工业噪声；小调静态和声循环
- **高技派 · Glitch**：bitcrush、采样率降级、随机 stutter/门限、颗粒化切片、
  音簇与不协和音程；节奏碎片化、错位、随机声像

### C3 音色编辑界面

- 通用宏参数（四风格共用）：明亮度 Brightness、起音 Attack、空间 Space、动态 Dynamics
- 风格专属参数（示例）：Techno = 失真 Drive / 共振 Resonance；
  Glitch = 故障度 Crush / 切碎率 Stutter / 随机度 Random
- 保留像素 UI 自绘控件（不使用 Tweakpane）；参数实时生效、播放中调整不爆音

### C4 技术路线

- 引入 **Tone.js（MIT，v15，UMD 可本地内置）** 承载 PolySynth / FMSynth / 效果链
  （BitCrusher、Distortion、Chorus、Filter、FeedbackDelay、Reverb）
- 保留现有自研 Web Audio 引擎作为轻量回退（Tone.js 加载失败时自动降级）
- 音色参数与调度解耦：Composition（纯数据）→ Synthesis（Tone 适配层）

### C5 验收标准

- 四风格音色差异明显；宏参数实时生效；播放中改参数不爆音
- 粗野主义/高技派与现有两风格在同一架构下可维护

## 7. 模块 D：建筑空间展示

### D1 Canvas 2D 剖视轴测（先做）

- 平面图 → 拉伸体块（无顶 / 剖视），等轴投影（isometric / 2:1 轴测）

- 交互：视图切换按钮（平面 / 轴测）；轴测视图只读或允许简单旋转（90° 步进）

## 8. 技术选型评估（2026-11-11 调研）

| 库 | 协议 | file:// 可行性 | 体积 | 结论 |
| --- | --- | --- | --- | --- |
| **Tone.js v15** | MIT | UMD `build/Tone.js` 可用；可下载到本地 | ~375KB | **推荐**（音色/效果/调度） |
| Tonal.js | MIT | v6 为 ESM-first；v2–v4 有 UMD 浏览器包 | ~20KB（v2 browser） | 可选；建议先自研轻量乐理（转调/和弦/进行 200–300 行） |
| Three.js | MIT | r161 起移除 UMD；r160 为最后 UMD（已弃用）；r147 最后含全局 addons | ~600KB+ | **暂不引入**（已选 Canvas 2D）；未来真 3D 时内置 r160 或构建版 |
| Tweakpane | MIT | v4 纯 ESM（classic script 报错）；v3 才有 UMD | ~50KB | **不推荐**（与像素 UI 风格冲突且 ESM 不便） |
| Strudel | AGPL-3.0 | 需 ESM / web component；协议要求衍生作品开源 | 较大 | **不嵌入**；仅借鉴 Tidal 模式思想（欧几里得/概率/模式变换） |

**补充建议**

- 欧几里得节奏、概率门限、和声模块自研（代码量小、可控、无依赖风险）
- 轴测用 Canvas 2D 自绘，不引入 Zdog/Three.js
- 若未来需要真实 3D：优先 Three.js r160 UMD（接受弃用警告）或引入构建流程

## 9. 工程与依赖策略

- 依赖策略变更：由「零依赖」升级为「**零网络依赖 + 允许内置第三方库**」
- 新增 `vendor/` 目录：存放 Tone.js 等库文件 + 各自 LICENSE（MIT 要求保留版权声明）
- 仍使用经典 `<script>`（非 module），保证 file:// 双击可用；版本锁定并记录来源
- 允许拆分文件（按需）：`index.html` + `js/composition.js` + `js/synthesis.js` +
  `js/render.js` + `vendor/tone.js`；拆分后仍保持双击可用
- 分层原则：**Composition（纯数据/算法）→ Synthesis（音色/效果）→ Render（Canvas）→ UI**

## 11. 风险与开放问题

1. Tone.js 体积与 file:// 兼容性需实测；其 npm 包为 ESM-first，需使用/验证 UMD 构建
2. 风格辨识度依赖人工试听调参，需要多轮试听
3. Glitch 风格在无采样的纯合成条件下表现力有边界（可考虑生成式噪声/短 buffer）
4. 「布局即种子」可能导致细微布局变化引起整段和声跳变，需评估感知平滑度
5. 升级后已有设计的和弦/鼓会变化——需要决定是否兼容旧种子（当前倾向不兼容）
6. 复杂度滑块与风格模板的边界（如 Ambient 复杂度拉满仍应克制）

## 12. 暂缓 / 不做

- 点击单个矩形试听、音阶下拉、TOUR 播放头动画（旧范围外项）
- 移动端适配
- 导出音频/视频（待核心稳定后评估）
- 用户自定义和弦编辑器（先做宏参数，暂不做完整音色编辑器）
