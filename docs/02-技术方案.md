# 02 · 技术方案 — ARCHISONIC: UNFINISHED TOUR

> 状态：v1.0（2026-11-10）。与 01-需求规范、03-设计规范、04-执行步骤 配套阅读。
> 红线：单文件、零依赖、零网络请求、file:// 可运行、无 ES Module。

## 1. 总体架构

单文件 `index.html`（UTF-8），内部三分区：

```
<style>     # 全部 CSS（设计规范落地，~460 行）
<body>      # 静态骨架：顶栏 / 舞台(FLOOR PLAN 窗口+canvas) / 底部面板四窗口 / 状态条
<script>    # 经典内联脚本（非 module），单 IIFE 'use strict'，按节组织（~1750 行）：
            #   §A CONFIG   色板/网格/映射参数/音阶表/和弦表
            #   §B STATE    文档状态、selection、撤销栈、tour 状态
            #   §C STORAGE  localStorage 读写/校验/防抖
            #   §D MAPPING  deriveParams 纯函数族
            #   §E AUDIO    AudioContext 生命周期、芯片 voice、lookahead 音序器
            #   §F RENDER   DPR 适配、网格、矩形/手柄/编号/播放头绘制
            #   §G INPUT    pointer 状态机、命中测试、快捷键
            #   §H UI       面板读数、控件绑定、状态文本
            #   §I INIT     启动序列（读档/播种/首帧/事件挂载）
```

模块间仅通过 `state` 对象与少量函数调用通信。预估总量 ~2300 行。

## 2. 数据模型

```js
// 空间对象（可 JSON 序列化，持久化单位）
space = { id: number, x, y, w, h }   // id 自增永不复用 = 创建顺序；x,y 为左上角 CSS px

// 文档状态
doc = { v: 1, spaces: [...], nextId: 1, bpm: 120, scaleId: 'cMinPent', masterVol: 0.7 }
selection = space.id | null          // 单选，仅会话内存
```

派生音乐参数（§D 纯函数，输入 space + 画布尺寸 + 音阶 + bpm）：

```js
// 音高：取中心 x，左低右高
t   = clamp((x + w/2) / W, 0, 1)
deg = Math.round(t * (N - 1))                              // 离散到音阶级数 0..N-1
midi = scale.root + scale.semitones[deg] + 12 * octShift
midi = clamp(midi, 24, 96)                                 // 安全钳制 C1..C7

// 时值：宽度 → 拍数，量化 1/4 拍
beats  = clamp(Math.round((0.25 + 3.75 * (w/W)) * 4) / 4, 0.25, 4)
durSec = beats * 60 / bpm                                  // 120BPM 时 0.125~2s
gateSec = Math.min(durSec * 0.85, 3.0)                     // 门时长，留 15% 间隙，封顶防长鸣

// 八度：取中心 y，三档（越靠上越高）
t = clamp(1 - (y + h/2) / H, 0, 1)
octShift = t < 0.25 ? -1 : (t > 0.75 ? +1 : 0)

// 音量：面积 → dB，sqrt 修正面积感知
a = clamp(w * h / (W * H), 0, 1)
gainDb = -21 + 15 * Math.sqrt(a)                           // [-21, -6] dB 单音
gainLin = Math.pow(10, gainDb / 20)                        // ≈ [0.089, 0.5]

// 和弦：伸长率 e = max(w/h, h/w)，见 §3.2
```

## 3. 映射规则定稿

### 3.1 音阶表（SCALE 下拉，默认 0）

| id | 名称 | 半音偏移 | 根音 midi | 气质 |
| --- | --- | --- | --- | --- |
| cMinPent | C MIN PENTA（默认） | [0,3,5,7,10] | 60 | 暗色、安全、芯片经典 |
| cMajPent | C MAJ PENTA | [0,2,4,7,9] | 60 | 明亮对比 |
| aNatMin | A NAT MINOR | [0,2,3,5,7,8,10] | 57 | 七音自然小调 |
| cPhryg | C PHRYGIAN | [0,1,3,5,7,8,10] | 60 | 异域、地下感 |

### 3.2 各参数映射（公式见 §2）

- 音高：中心 x → 音阶级数（round 离散，保证任意位置落在调内，相邻矩形音高分明）
- 时值：宽度 → 0.25–4 拍；BPM 作为全局时值缩放
- 八度：中心 y 三档 −1 / 0 / +1（上 1/4 区 / 中 1/2 区 / 下 1/4 区）
- 音量：面积 → −21~−6 dB
- 和弦：宽高比 → 三音和弦（与 NES 三声道气质对齐）：

| e = max(w/h, h/w) | 和弦 | 构成音（相对根音半音） |
| --- | --- | --- |
| [1.00, 1.15) | PWR5 | 0, 7, 12 |
| [1.15, 1.60) | SUS4 | 0, 5, 7 |
| [1.60, 2.40) | MIN | 0, 3, 7 |
| [2.40, ∞) | DIM | 0, 3, 6 |

### 3.3 TOUR 顺序

按创建顺序（id 升序）。矩形上显示的编号 = 当前数组位置 + 1（删除后重排，始终与巡游顺序一致）。
播完全部后停止，不循环。

## 4. 交互状态机（智能模式）

### 4.1 命中优先级（pointerdown 时判定一次）

1. 选中矩形的 8 个手柄（4 角 + 4 边中点，命中阈值 8px）→ resizing
2. 倒序遍历矩形（最后绘制 = 最上层）命中矩形体 → moving
3. 空白 → creating

### 4.2 状态转换表

| 状态 | 事件 | 动作 |
| --- | --- | --- |
| idle | 空白拖拽 ≥3px | creating：橡皮筋预览 + W/H 标注 |
| creating | pointerup | ≥16×16 则创建+选中+试听，否则丢弃；入撤销栈 |
| creating | Esc / pointercancel | 取消 |
| idle | 矩形体拖拽 ≥3px | moving：记录偏移 |
| moving | pointermove | 平移 + 边界钳制 |
| moving | pointerup | 入撤销栈 + 自动试听一次 |
| moving | 点击（<3px 位移） | 选中 + 试听 |
| moving | Esc | 还原拖拽前位置 |
| idle | 手柄拖拽 | resizing：按方向缩放（对角/对边固定） |
| resizing | pointermove | 缩放 + 最小 16×16 + 边界钳制 |
| resizing | pointerup | 入撤销栈 + 自动试听一次 |
| resizing | Esc / pointercancel | 还原起始几何 |

### 4.3 实现要点

- Pointer Events + setPointerCapture（拖出画布不丢事件）；canvas 设 touch-action:none；body user-select:none
- 点击判定统一在 pointerup 按位移阈值（不用 click 事件，避免与拖拽双触发）
- 光标：手柄上 8 向 resize 光标、矩形体 move、空白 crosshair
- 快捷键（document keydown，焦点在表单控件时放行）：
  - Delete / Backspace 删除选中
  - Ctrl+Z 撤销（必须 preventDefault，防焦点在滑杆时触发原生撤销）
  - Esc：拖拽中 = 取消还原；空闲 = 取消选中；TOUR 中 = 停止
  - Space：TOUR / STOP 切换（preventDefault 防页面滚动）

### 4.4 撤销栈

命令对象（纯数据，双栈 undo/redo，上限 100，仅会话内存）：

- {t:'add', id, rect} / {t:'remove', id, rect, index}
- {t:'move', id, before, after} / {t:'resize', id, before, after}
- {t:'clear', spaces:[...]}（清空可整体撤销）

每手势至多一条；新命令清空 redo 栈；id 自增永不复用。

## 5. 画布渲染

- fitCanvas：backing = CSS 尺寸 × min(devicePixelRatio, 2)（封顶防 4K 开销）；ctx.setTransform(dpr,…) 后全按 CSS px 绘制
- 触发：window resize + ResizeObserver + rAF 中比对 dpr 变化
- 网格：24px 小格 rgba(216,216,214,0.08)；96px 强调线 rgba(216,216,214,0.18)
- 脏标记渲染：编辑/状态变化 requestRender()；TOUR 期间 rAF 持续；空闲零 CPU
- 矩形：填充 #D8D8D6(α0.95) + 2px #303030 描边；选中 = 2px #B8E83E + 8 个 7×7px 酸绿手柄（1px 深边）；TOUR 当前 = 酸绿 α0.30 叠加 + 3px 扫掠光点（shadowBlur 8，x = rect.x + progress×w）
- 编号：Courier New 11px 酸绿，矩形内左上角 3px；w<28 或 h<18 时跳过；TOUR 态翻深色
- 橡皮筋：2px 虚线酸绿 + 光标旁 W/H 等宽小字
- 空状态浮层：居中闪烁提示（EMPTY LOT. DRAG TO DRAW A RECTANGLE. / CLICK A RECT TO HEAR ITS CHORD. / PRESS [TOUR] TO PLAY.）

## 6. 音频设计

### 6.1 AudioContext 生命周期

- 懒创建：首次用户手势（pointerdown / Space keydown）内 ensureAudio()：new AudioContext + resume()
- 顶栏未解锁前显示 AUDIO: STANDBY — CLICK A RECT TO ARM；解锁后 AUDIO: READY

### 6.2 信号链

voice → masterGain → DynamicsCompressor → destination

- masterGain.gain = pow(masterVol, 1.5) × 0.7（感知曲线 + 防削波）
- Compressor：threshold −14dB、ratio 3:1、knee 12

### 6.3 芯片音色（每音一个 voice，两振荡器）

- osc1 square 主频 f，detune +3 cents；osc2 square f/2（sub，增益 0.35），detune −3 cents
- 包络：Attack 5ms → 1.0；Decay 60ms → 0.35；Sustain 至 gateSec；Release setTargetAtTime(0, gateEnd, 0.05)
- osc.start(t) / osc.stop(t + gateSec + 0.3)；onended 断开交给 GC
- 活跃 voice Set 上限 96，超出强停最旧（5ms 快衰减）

### 6.4 点击试听（芯片琶音 chip strum）

- 和弦音 35ms 错开依次进入；总时长 max(0.45s, min(gateSec, 0.8s))
- 移动 / 缩放 / 创建落定后自动试听一次（拖拽过程中不发声）

### 6.5 TOUR 音序器（lookahead 调度）

- startTour：ensureAudio → 构建 plan 快照 [{id, notes:[{f,gainLin}], durSec, gateSec}]（快照保证巡游中编辑不影响已排程）→ step=0, nextTime=ctx.currentTime+0.06 → setInterval(25ms, scheduleAhead) → 播放头 rAF
- scheduleAhead：while step<plan.length 且 nextTime < now+0.15：playVoice(...) + visualQ.push({id, t:nextTime, dur}) + nextTime += durSec+0.015（15ms 断奏留白）+ step++
- 自然结束（step 耗尽且 now > nextTime）与手动 STOP 共用 stopTour：clearInterval + activeVoices 全 kill（30ms 快衰减）+ visualQ 清空 + 播放头 rAF 停 + UI 复位
- 巡游中调 BPM / 音阶 / 音量：前瞻窗内已排程保持旧值，其后按新值（下次巡游全量生效）
- visibilitychange 回前台：nextTime 与 ctx.currentTime 重同步，防猛然堆叠发声
- 播放头同步：rAF 每帧读 ctx.currentTime 线性扫 visualQ 找当前条目 → 绘制高亮 + progress=(now−t)/dur 扫掠线（矩形被删则只跳过绘制，音频照常）

## 7. 持久化

- key：`archisonic.doc.v1`（产品前缀防 file:// 全域同源冲突）；存 {v, spaces, nextId, bpm, scaleId, masterVol}
- 保存时机：操作落定后 debounce 300ms
- 读档：try/catch + 字段类型校验 + 数值钳制；失败静默回退默认
- 种子：无存档时播种 5 矩形（比例坐标，覆盖 4 档和弦 + 高低八度），立即落盘；清空后不再播种
  参考（×W, ×H 换算）：{0.07,0.55,0.13,0.16} / {0.25,0.42,0.08,0.08} / {0.36,0.30,0.06,0.26} / {0.46,0.42,0.10,0.10} / {0.60,0.24,0.07,0.07}

## 9. 风险与对策（摘要）

| 风险 | 对策 |
| --- | --- |
| file:// 下 ES Module 被 CORS 拦截 | 只写经典内联 script，全文件无 import / fetch / link |
| 自动播放策略（ctx 初始 suspended） | 懒创建 + 手势内 resume + STANDBY 提示 |
| 拖拽出画布丢事件 | setPointerCapture + pointercancel 视同 Esc + touch-action:none |
| 高分屏模糊 / 跨屏 dpr 变化 | backing × dpr（封顶 2）+ rAF 比对 dpr + ResizeObserver |
| Ctrl+Z 与原生控件撤销打架 | document keydown preventDefault；表单控件焦点放行 |
| 后台标签页 interval 节流 | 已知限制；visibilitychange 重同步 |
| 振荡器泄漏 / 爆音 | start/stop 带余量 + onended 断开 + voice 上限 96 + compressor 兜底 |
| localStorage 损坏 / 旧 schema | try/catch + 字段校验 + 回退默认；v 字段预留迁移 |
| 窗口 resize 导致映射漂移 | 接受为特性（相对映射）；TOUR 音频用快照不受影响 |
| 双击选中幽灵文本 | body user-select:none |
