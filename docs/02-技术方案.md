# 02 · 技术方案 — ARCHISONIC: UNFINISHED TOUR

> 状态：v2.0（2026-11-10）。v1 产品方案（PAD + C 大调进行 + 连接性）的技术实现标准。
> 红线：单文件、零依赖、零网络请求、file:// 可运行、无 ES Module、经典内联 script。

## 1. 总体架构

单文件 `index.html`（UTF-8），内部三分区：

```
<style>     # 全部 CSS（设计规范落地）
<body>      # 静态骨架：顶栏 / FLOOR PLAN 窗口(canvas+空状态浮层) / 底部三窗口 / 状态条
<script>    # 经典内联脚本，单 IIFE 'use strict'，按节组织：
            #   §A CONFIG   色板/网格常量/进行表/和弦音高
            #   §B STATE    文档状态、selection、撤销栈、播放状态
            #   §C MAPPING  连接判定、进行分配（纯函数）
            #   §D AUDIO    AudioContext、PAD voice、程序化混响、播放调度
            #   §E RENDER   网格、平面图矩形、选中态、播放高亮、编号
            #   §F INPUT    pointer 状态机、命中测试、快捷键
            #   §G UI       面板读数、控件绑定、状态文本
            #   §H INIT     启动序列（首帧、事件挂载）
```

（v1 无 STORAGE 节——持久化列入后续版本。）

## 2. 数据模型


## 3. 连接判定（共边或重叠，仅角相触不算）

连续两矩形 A、B（按创建顺序相邻，A = 前，B = 后）：

- **重叠**：max(A.x,B.x) < min(A.x+A.w,B.x+B.w) 且 max(A.y,B.y) < min(A.y+A.h,B.y+B.h)
- **共边**：
  - 左右相贴（A.x+A.w === B.x 或 B.x+B.w === A.x）且纵向区间严格相交：max(A.y,B.y) < min(A.y+A.h,B.y+B.h)
  - 上下相贴（A.y+A.h === B.y 或 B.y+B.h === A.y）且横向区间严格相交：max(A.x,B.x) < min(A.x+A.w,B.x+B.w)
- 仅角相触：某区间相交长度为 0，被严格不等号自然排除 ✓

实现为纯函数 `areConnected(A, B) → bool`（区间比较全部用严格不等号 + 相等边界判定）。

## 4. 和弦进行（C 大调，数量决定）

```js
PROGRESSIONS = {
  1: ['C'],
  2: ['C','F'],
  3: ['Dm','G','C'],
  4: ['Dm','G','C','Am'],
}
buildProgression(n):
  n <= 4 → PROGRESSIONS[n]
  n >= 5 → 循环 ['Dm','G','C','Am']（第 5 个 = Dm）
```

和弦音高（midi，密集排列，PAD 友好）：

| 和弦 | midi |
| --- | --- |
| C | 48, 52, 55 |
| F | 48, 53, 57 |
| Dm | 50, 53, 57 |
| G | 50, 55, 59 |
| Am | 57, 60, 64 |

任何增删/撤销操作后，全部矩形的和弦按当前数量重算（纯函数，无状态缓存）。

## 5. PAD 音色（每和弦一个 voice）

- 振荡器：saw ×2（±7 cents 失谐）+ triangle 低八度（增益 0.5）
- 每 voice 一个 lowpass（cutoff ~900Hz）+ LFO（osc → gain 0.12 → frequency，±150Hz @0.3Hz，缓慢呼吸感）
- 包络（voice 内 gain）：
  - attack 0.6s（linearRamp，慢、软、冲击力弱）
  - sustain 至发声时长 D=3.0s
  - release 1.2s；**legato 对 release 延长至 1.6s**（尾音交叠进下一和弦）
- 每振荡器增益 ~0.12；masterGain（音量滑杆，pow(vol,1.5)×0.7）→ DynamicsCompressor（−14dB / 3:1 / knee 12）→ destination
- 振荡器生命周期：start(t)/stop(t+D+2s)，onended 断开；activeVoices Set 跟踪，上限 64 超出强停最旧

## 6. 混响（面积决定强度）

- 程序化脉冲响应：2.5s 立体声噪声，指数衰减（exp(−t×2.2)），生成一次存入 AudioBuffer → 单个共享 ConvolverNode
- 每和弦 wet 增益 = 0.15 + 0.65 × clamp(面积/(W×H), 0, 1) → [0.15, 0.8]，面积越大混响越重
- 路由：voice → dryGain(0.8) → master；voice → wetGain(每和弦) → convolver → master
- W、H = 画布 CSS 尺寸；播放瞬间快照计算

## 7. 播放调度（PLAY）

- PLAY 按下（首次手势内 ensureAudio）：
  1. 快照：spaces 数组 + 画布尺寸 + 进行表 → plan = [{id, notes[], wetGain, start, dur, legatoNext}]
  2. 时间线：起点 t0 = ctx.currentTime + 0.15；每和弦 D = 3.0s
     - 下一矩形连接 → 下一和弦 start = 本 start + D − 0.35（0.35s 交叉重叠 = legato）
     - 不相连 → 下一和弦 start = 本 start + D + 0.5（0.5s 停顿 = 断开）
  3. 全部和弦用绝对时间一次性排程（无需定时器驱动）
- 播放高亮：rAF 每帧线性扫时间线 → 当前和弦矩形酸绿描边；播放结束自动复位
- STOP：activeVoices 全部快衰减（30ms）强停 + rAF 停 + 状态复位；再按 PLAY 重新开始
- 播放中编辑画布不影响本次播放（快照），播放结束后编辑生效
- 0 矩形时 PLAY 不启动；快速 PLAY/STOP 交替无多重振荡器（每次 START 前先 kill 残留）

## 8. AudioContext 生命周期

- 懒创建：首次手势（canvas pointerdown / PLAY 点击）内 new AudioContext + resume
- 顶栏状态：未解锁 AUDIO: STANDBY — PRESS PLAY TO ARM；解锁后 AUDIO: READY

## 9. 交互状态机（智能模式，沿用 v1 文档设计）

- 命中优先级：选中矩形的 8 手柄（阈值 8px）> 矩形体（倒序，最上层优先）> 空白
- 状态转换：
  - 空白拖拽 ≥3px → creating（橡皮筋预览 + W/H 标注）；pointerup ≥16×16 创建 + 选中，否则丢弃
  - 矩形体拖拽 ≥3px → moving；pointerup 入撤销栈；点击（<3px）→ 选中
  - 手柄拖拽 → resizing（对角/对边固定）；最小 16×16 + 边界钳制
  - Esc：拖拽中 = 取消还原；空闲 = 取消选中；播放中 = STOP
- Pointer Events + setPointerCapture；canvas touch-action:none；body user-select:none
- 快捷键（document keydown，表单控件焦点时放行）：Delete/Backspace 删除；Ctrl+Z 撤销（preventDefault）；Space = PLAY/STOP 切换
- 撤销栈：命令对象 {t:'add'|'remove'|'move'|'resize'|'clear', ...}，双栈上限 100，仅会话内存

## 10. 画布渲染

- fitCanvas：backing = CSS 尺寸 × min(devicePixelRatio, 2)；ctx.setTransform(dpr) 后按 CSS px 绘制
- 触发：window resize + ResizeObserver + rAF 中比对 dpr
- 脏标记渲染：编辑/状态变化 requestRender()；播放期间 rAF 持续；空闲零 CPU
- 网格：24px 小格 rgba(216,216,214,0.08) + 96px 强调线 rgba(216,216,214,0.18)
- 平面图矩形（docs/03 §4.5）：地板填充 #D8D8D6 → 墙体 8px 描边 #B5B5B3 → 墙体内侧 1px #303030 分界线 → 选中态 #B8E83E 描边 + 8 手柄 → 播放高亮 #B8E83E 描边（闪烁）
- 编号：11px 等宽 #B8E83E，矩形内左上角 3px；w<28 或 h<18 跳过
- 橡皮筋：2px 虚线 #B8E83E + 光标旁 W/H 等宽小字
- 空状态浮层（DOM）：居中闪烁「EMPTY LOT. DRAG TO DRAW A RECTANGLE.」；有矩形时隐藏

## 11. UI 布局

- 顶栏 44px：左 品牌（Georgia 斜体 22px + 等宽副题）｜中 状态文本 + 闪烁块｜右 PLAY/STOP 按钮（主按钮）

## 12. 风险与对策（摘要）

| 风险 | 对策 |
| --- | --- |
| file:// 下 ES Module 被 CORS 拦截 | 只写经典内联 script，全文件无 import / fetch / link |
| 自动播放策略（ctx 初始 suspended） | 懒创建 + 手势内 resume + STANDBY 提示 |
| PAD 慢起音导致连续操作堆叠 | activeVoices 上限 64 强停最旧；PLAY 前先 kill 残留 |
| Convolver 计算开销 | 单个共享卷积器；脉冲响应仅 2.5s 立体声，生成一次复用 |
| 高分屏模糊 / 跨屏 dpr 变化 | backing × dpr（封顶 2）+ rAF 比对 + ResizeObserver |
| Ctrl+Z 与原生控件撤销打架 | document keydown preventDefault；表单控件焦点放行 |
| 拖拽出画布丢事件 | setPointerCapture + pointercancel 视同 Esc |
| 窗口 resize 导致混响映射漂移 | 播放用按下瞬间快照，resize 只影响下次播放 |
| 振荡器泄漏 / 爆音 | start/stop 带余量 + onended 断开 + compressor 兜底 |
