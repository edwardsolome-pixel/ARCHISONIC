> 红线：零依赖、零网络请求、file:// 可运行、无 ES Module、经典内联 script。

## 3. 连接判定（共边或重叠，仅角相触不算）

连续两矩形 A、B（按创建顺序相邻）：

- **重叠**：max(A.x,B.x) < min(A.x+A.w,B.x+B.w) 且 max(A.y,B.y) < min(A.y+A.h,B.y+B.h)
- **共边**（±2px 容差 TOUCH_EPS）：
  - 左右相贴（|A.x+A.w − B.x| ≤ 2 或 |B.x+B.w − A.x| ≤ 2）且纵向区间严格相交
  - 上下相贴（|A.y+A.h − B.y| ≤ 2 或 |B.y+B.h − A.y| ≤ 2）且横向区间严格相交
- 仅角相触：区间相交长度为 0，被严格不等号自然排除

实现：`areConnected(A, B) → bool`。

## 5. 音色（每和弦一个 voice，按 doc.timbre 配置）

| 音色 | 振荡器层 | 包络/滤波 | 混响系数 |
| --- | --- | --- | --- |
| 古典主义（默认） | sawtooth ×2（detune ±7，gain 0.11）+ triangle 低八度（mult 0.5，gain 0.055） | attack 0.3s；sustain 1.0；decay 0；lowpass 900Hz Q 0.5；LFO 0.3Hz ±120Hz | 1.0 |
| 现代主义 | square（+24 cents，0.13）+ triangle（−12 cents，0.23）+ square（0，0.06）+ triangle 高八度（mult 2，+5 cents，0.035） | attack 0.02s；sustain 0.1；decay 0.1；lowpass 3300Hz Q 0.7；LFO 5Hz ±3Hz | 0.9 |

- 包络：attack →（可选 decay 到 sustain）→ sustain → release（调度传入：legato 1.5拍 / 断开 0.5拍）
- 信号链：voice → keysTrackGain（= keyVol，0–1，滑块 setTargetAtTime 0.02s 即时生效）
  → dryBus(0.8) / wetGain / delaySend
- masterGain（pow(masterVol,1.5)×0.7）→ DynamicsCompressor（−14dB / 3:1 / knee 12）→ destination
- 振荡器生命周期：start(t)/stop(end+release+0.1)；activeVoices 跟踪，上限 64 超出强停最旧
- 播放中切换音色：已排程和弦保持原音色，下一遍循环按新音色

## 6. 效果发送（尺寸决定强度）

- **混响**：程序化脉冲响应（2.5s 立体声噪声，指数衰减 `(1−i/len)^2.0`）→ 单个共享 ConvolverNode
  - t = clamp((min(w,h) − 36) / (240 − 36), 0, 1)
  - wet = t × 1.0 × reverbScale（古典 1.0 / 现代 0.9）
  - 短边 ≤36px 完全无混响；≥240px 拉满
- **延时**：单个共享 DelayNode + 反馈 0.3
  - 延时时间 = 附点八分（0.75 × spb = 0.75 × 60/bpm；120BPM = 0.375s）；BPM 变化时 setTargetAtTime 平滑跟随（时间常数 0.1）
  - send = t × 0.8；短边 ≤36px 无回声、≥240px 拉满
- 路由：和弦 → keysTrackGain → dry / wet→convolver / dly→delayLine（反馈环）→ masterGain
- STOP：delayFB 快衰减至 0（时间常数 0.02s），0.5s 后恢复 0.3（此时已静音，无爆音）

## 7. 播放调度（PLAY）

- PLAY 按下（首次手势内 ensureAudio）→ **循环模式**（不按 STOP 一直循环）：
  1. 快照 loopPlan = [{id, midi, wet, dly, legato}]；legato = 相邻矩形连接判定（段内）；
     循环衔接永远无缝（不再按首尾矩形连接判定）
  2. t0 = ctx.currentTime + 0.05；和弦、节拍器、鼓共用此时间网格
  3. schedulePass(t, from)：按绝对时间排一遍（spb = 60/bpm，每遍使用当前 BPM）
     - 每和弦 1 小节（4 拍，SLOT_BEATS）槽位；起点严格落槽位 = 节拍器重音
     - 奇数个和弦：末和弦重复一遍（legato），凑成偶数次
     - legato：gate 4拍 + release 1.5拍（尾音叠进下一和弦）
     - 断开：gate 3拍 + release 0.5拍（0.5拍停顿后下一和弦落槽位）
     - 返回完整遍时长（偶数重复后 × 槽位）；键盘静音时跳过 playChord 但网格照常
  4. loopScheduler（setInterval 200ms）：每遍快结束（提前 2s）时按当前 BPM 预排下一遍；修剪过期时间线
  5. 节拍器（METRO，仅播放时响）：前瞻 0.3s 排程方波点击（重音 1320Hz / 常规 880Hz，0.05s 衰减）；
     播放中启动时对齐到当前循环网格（从当前拍继续，重音相位与和弦槽位一致）
  6. 键盘轨道：静音立即生效（kill 全部 activeVoices + dampDelay 掐回声尾）；
     取消静音时从下一槽位 schedulePass(t, from) 恢复当前遍剩余排程
- 播放高亮：rAF 每帧线性扫时间线 → 当前和弦矩形酸绿描边；无自然结束
- STOP / Esc / Space：clearInterval + activeVoices 快衰减强停 + killDrumVoices + 状态复位
- 播放中编辑画布不影响本次播放（快照）；0 矩形时 PLAY 不启动

## 8. 鼓机（16 步音序器）

- 鼓型：全部门窗汇总（按创建顺序）——门 → KICK_STEPS=[0,8,4,12]（底鼓+军鼓叠奏）；
  窗 → HAT_STEPS=[2,6,10,14]（踩镲 vel 0.65/0.5 轻重交替）；每类最多 4 个；startPlay 时快照
- 调度：drumStepNext 与和弦/节拍器同网格（t0 对齐）；loopScheduler 内前瞻 0.3s 按步发鼓；
  步长 spb/4 实时随 BPM；16 步循环；鼓静音时只推进不发鼓
- 音色：kick = sine 160→46Hz 扫频 0.09s + 0.28s 指数衰减；
  snare = 噪声 bandpass 1800Hz Q0.8 0.12s + triangle 200Hz 0.07s；
  hat = 噪声 highpass 7500Hz 0.035s；共享 1s 噪声 buffer（ensureAudio 生成一次）
- 路由：鼓 voice → drumTrackGain（= drumVol，滑块即时生效）→ masterGain；干声不送混响/延时
- drumVoices 独立列表（上限 64）；STOP / 鼓静音 → killDrumVoices（0.008s 快衰减 + 120ms 后断开）

## 9. AudioContext 生命周期

- 懒创建：首次手势（canvas pointerdown / PLAY / 公告 OK 后的 LETS DESIGN）内 new AudioContext + resume
- TRANSPORT 面板的 AUDIO 读数：初始 `AUDIO: STANDBY`，解锁后 `AUDIO: READY`

## 10. 交互状态机（智能模式）

- 命中优先级：选中矩形的 8 手柄（阈值 8px）> 矩形体（倒序，最上层优先，外扩 4px 覆盖墙体）> 空白
- 状态转换：
  - 空白拖拽 ≥3px → creating（橡皮筋预览 + W/H 标注）；pointerup ≥16×16 创建 + 选中，否则丢弃
  - 矩形体拖拽 ≥3px → moving；pointerup 入撤销栈；点击（<3px）→ 选中
  - 手柄拖拽 → resizing（对角/对边固定）；最小 16×16 + 边界钳制
  - Esc：拖拽中 = 取消还原；构件工具 = 取消工具；空闲 = 取消选中；播放中 = STOP（优先级：播放 > 工具 > 拖拽/选中）
- 构件工具（doc.tool 非空）：pointerdown 只走 hitEdge；点击画布空白取消工具；光标为 default；隐藏选中缩放框
- Pointer Events + setPointerCapture；canvas touch-action:none；body user-select:none
- 快捷键（document keydown）：表单控件焦点时放行原生行为；按钮焦点时仅 Space/Enter 放行，其余走全局快捷键；
  按钮/滑杆操作后自动 blur 归还焦点——Delete/Backspace 删除；Ctrl+Z 撤销（preventDefault）；Space = PLAY/STOP
- 撤销栈：每手势至多一条；上限 100；redoStack 保留但未绑定快捷键（仅 Ctrl+Z 撤销）。
  命令类型：矩形 add / remove / move / resize（快照数据对象）；门窗新增 / 删除为自定义 do/undo 命令。

## 11. 画布渲染

- fitCanvas：backing = CSS 尺寸 × min(devicePixelRatio, 2)；ctx.setTransform(dpr) 后按 CSS px 绘制
- 触发：window resize + ResizeObserver(canvasBody)
- 脏标记渲染：编辑/状态变化 requestRender()；播放期间 rAF 持续；空闲零 CPU
- 绘制顺序：网格 → 全部矩形 → 橡皮筋 → 选中态（构件工具激活时跳过）→ 构件开口 → 播放高亮
- 画布背景 #B5B5B3；网格 24px 小格 rgba(48,48,48,0.10) + 96px 强调线 rgba(48,48,48,0.22)
- 平面图矩形：地板填充 #D8D8D6 → 墙体 8px 描边 #525252（用 evenodd 裁剪排除其他矩形区域，重叠处不画墙）
  → 墙体内侧 1px #B5B5B3 分界线 → 编号（11px "IPix"，#B8E83E，自墙体内缘再内缩 2px；w<28 或 h<18 跳过）
- 选中态：2px #B8E83E 外描边 + 8 个 7×7px 手柄（1px #525252 内边）
- 橡皮筋：2px 虚线 #B8E83E + 光标旁 W/H 标注（11px "Courier New"）
- 播放高亮：当前发声矩形 2px #B8E83E 描边（无闪烁）
- 空状态浮层（DOM）：居中闪烁「EMPTY LOT. DRAG TO DRAW A RECTANGLE.」+ 副行；有矩形时隐藏

## 12. 构件开口（门 / 窗）

- 数据：space.openings（side/t/type）；移动/缩放天然保持（t 相对）
- 交互：工具激活时只响应墙边 ±7px（最上层优先）；点击已有门窗（中心距 < 半长+4px）→ 删除；
  新开口与已有重叠（中心距 < 两者半长之和）→ 忽略；t 钳制使开口完整落在边上且距墙角交点预留 5px
  （边短于开口+2×5px 则忽略）；操作入撤销栈
- 渲染（drawOpenings）：
  - 门：40×10px 灰板条 #B5B5B3 覆盖墙体
  - 窗：先以画布底色打掉 26×8 墙体；再画 26×5px 半透明白条 rgba(216,216,214,0.5)（位于墙体中线一侧）；
    最后 3 条 1px #303030 细线，平行于墙（垂直于墙壁断面），间距 3.5px

## 14. 风险与对策（摘要）

| 风险 | 对策 |
| --- | --- |
| file:// 下 ES Module / 外部 .ttf 被 CORS 拦截 | 经典内联 script；字体以 base64 data URI 嵌入 fonts.css |
| 浏览器自动播放策略（OS 音乐 / AudioContext） | 公告 OK 点击作为手势解锁 OST；AudioContext 首次手势懒创建 + resume |
| 拖拽出画布丢事件 | setPointerCapture + pointercancel 视同 Esc |
| 高分屏模糊 / 跨屏 dpr 变化 | backing × dpr（封顶 2）+ resize/ResizeObserver |
| Ctrl+Z 与原生控件撤销打架 | document keydown preventDefault；表单控件焦点放行 |
| 点击按钮后快捷键失灵 | 按钮仅放行 Space/Enter；操作后 blur 归还焦点 |
| 后台标签页 interval 节流 | 已知限制（音频调度基于 AudioContext 时钟，抖动小于视觉） |
| 振荡器泄漏 / 爆音 | start/stop 带余量 + voice 上限 64 + compressor 兜底 |
| 鼓信号无声（曾发生） | drumTrackGain 必须连接 masterGain（已修复并在此记录） |
| 播放键尺寸切换导致布局跳动 | 播放键绝对居中 + player-body 固定高度 |
| 窗口 resize 导致效果映射漂移 | 播放用按下瞬间快照，resize 只影响下次播放 |
